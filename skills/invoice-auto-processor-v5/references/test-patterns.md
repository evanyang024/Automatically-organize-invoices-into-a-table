# 发票处理工具 — 测试与验证

## 模拟发票创建

使用 pymupdf 直接创建含中文发票文本的 PDF，无需真实发票即可测试全流程：

```python
import fitz

doc = fitz.open()
page = doc.new_page(width=595, height=842)

invoice_text = """增值税电子普通发票
发票代码：044001900111
发票号码：12345678
开票日期：2024年03月15日

货物或应税劳务、服务名称
*信息技术服务*软件开发服务*次*1*5000.00*5000.00*6%*300.00
*信息技术服务*技术咨询*次*2*2000.00*4000.00*6%*240.00

（小写）¥9000.00
税额 ¥540.00
价税合计 ¥9,540.00
备注：项目开发与咨询服务
"""

page.insert_text((50, 50), invoice_text, fontname="china-s", fontsize=10)
doc.save("input/测试发票.pdf")
doc.close()
```

## 测试流程

```bash
# 1. 清空测试环境
rm -f input/*.pdf archive/*.pdf output/*.xlsx

# 2. 创建模拟发票（见上）
# 3. 单次运行
python run.py --once

# 4. 三步验证
ls input/     # 应为空
ls archive/   # 应有重命名后的 PDF
ls output/    # 应有 发票台账.xlsx
```

## 验证检查点

| 检查项 | 预期结果 |
|--------|----------|
| input/ 为空 | 所有文件已处理+归档 |
| archive/ 文件名 | 格式 `YYYY-MM-DD-项目-金额.pdf` |
| Excel 行数 | 1 表头 + N 明细行 |
| 明细字段 | 货物名称、规格、数量、单价、金额、税率逐项正确 |
| 汇总字段 | 不含税/税额/价税在每行一致 |
| 去重 | 同张发票第二次放入时日志显示"已存在，跳过" |

## 日志关键信号

```
✅ 重命名: 旧名 → 新名            # 重命名成功
✅ [文件名] ✅ 处理完成            # 全流程完成
⚠️ 发票号码 xxx 已存在，跳过       # 去重生效
❌ [文件名] ❌ 处理失败           # 需查看 invoice_processor.log
```
