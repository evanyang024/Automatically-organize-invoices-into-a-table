# 发票去重跟踪机制

## 设计

不污染 Excel 台账列结构（台账只保留用户要求的 3 列），用独立 JSON 文件跟踪已处理的发票号码。

- **文件**: `output/.processed_invoices.json`（点号开头，文件管理器默认隐藏）
- **格式**: JSON 数组 `["26317907110500150554", "26317907120500131367", ...]`
- **读写时机**: 每处理一张发票 → 立即写入（追加模式）

## 去重流程

```
新发票 → 解析发票号码
       → 查 .processed_invoices.json
       → 已存在? → 跳过（不写台账、不归档）
       → 不存在? → 写台账 → 归档 → 标记已处理
```

## 与旧方案对比

| | 旧方案（已废弃） | 新方案 |
|------|------|------|
| 去重依据 | 台账第一列（货物名）| 发票号码 |
| 存储 | 读 Excel 列 | 独立 JSON 文件 |
| 可靠性 | ❌ 货物名相同就跳过 | ✅ 按发票号码精确匹配 |
| 对台账污染 | 无 | 无 |

## 维护

- 首次运行时文件自动创建
- 文件丢失 → 所有发票视为新发票（会重复写入 Excel）
- 手动清理：删除 `output/.processed_invoices.json` 后重跑，会重建完整台账
