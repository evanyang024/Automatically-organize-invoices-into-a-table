# 项目名称清理规则（v8）

## 清理顺序（不可调换）

```python
_TRUNCATE_KEYWORDS = ['沪房地', '不动产权', '产权证书', '规格型号', '单位']

for item in items:
    name = item.get("货物或服务名称", "")
    # 1. 去星号
    name = re.sub(r'\*', '', name)
    # 2. 去括号及后面内容
    name = re.split(r'[（(]', name)[0].strip()
    # 3. 关键词截断
    for kw in _TRUNCATE_KEYWORDS:
        if kw in name:
            name = name[:name.index(kw)].strip()
            break
    # 4. 去末尾"无"
    if name.endswith('无'):
        name = name[:-1].strip()
    item["货物或服务名称"] = name
```

## 规则详解

### 规则1: 去星号
- **输入**: `*供电*扫码充电-` 或 `*供电**供电*扫码充电-`
- **输出**: `供电扫码充电-`
- **原因**: 星号格式 `*分类*名称` 的分类部分混入了名称

### 规则2: 去括号
- **输入**: `95号车用汽油(ⅥB` 或 `95号车用汽油（VI`
- **输出**: `95号车用汽油`
- **原因**: 括号内是油品等级代码（ⅥB = 国六B），用户不需要

### 规则3: 关键词截断
- **输入**: `车辆停放沪房地(浦)字(2008)第(063`
- **输出**: `车辆停放`
- **原因**: 不动产发票的产权证书号混入了项目名称
- **关键词列表**: `沪房地`, `不动产权`, `产权证书`, `规格型号`, `单位`

### 规则4: 去末尾"无"
- **输入**: `车辆停放无`
- **输出**: `车辆停放`
- **原因**: 不动产发票中"无"表示无产权证号，混入了项目名称

### 规则5: 非税收入票据去数字前缀（在正则层面处理）
- **输入**: `056990124020 发明专利第2年年费`
- **输出**: `发明专利第2年年费`
- **原因**: 项目编码和项目名称在同一行，需要正则只捕获专利类型后面的文本
- **正则**: `(?:\d+\s*)((?:发明|实用新型|外观设计)专利[^\n]*)`

## 票据类型与清理规则对应

| 票据类型 | 触发的规则 | 示例 |
|---------|-----------|------|
| 加油发票 | 规则2 | `95号车用汽油(ⅥB` → `95号车用汽油` |
| 充电发票 | 规则1 | `*供电*扫码充电-` → `供电扫码充电-` |
| 不动产停车发票 | 规则3+4 | `车辆停放无` → `车辆停放` |
| 非税收入票据 | 规则5 | `056990124020 发明专利第2年年费` → `发明专利第2年年费` |
| 通行费票据 | 无需清理 | `车辆通行费` 已是正确名称 |
| 住宿发票 | 无需清理 | `住宿费` 已是正确名称 |
