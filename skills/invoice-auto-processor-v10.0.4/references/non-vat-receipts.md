# 非增值税发票类型参考（v8 已实现）

本文档记录已支持的非标准增值税发票的文本结构和解析逻辑。

## 1. 中央非税收入统一票据（电子）

**示例**: 专利费135.pdf

**特征**:
- 标题: `中央非税收入统一票据（电子）`
- 字段名: `票据号码`（不是"发票号码"）
- 日期格式: `YYYY-MM-DD`（如 `2026-03-11`）
- 金额结构特殊:
  - 有"标准"列（如 `0.15`）和"金额"列（如 `900.00`）
  - 实际价税合计在"金额合计（大写）"处（如 `135.00`）
  - 策略4取最大数字会错误地取到 `900.00`

**v8 解析逻辑**:
- 票据号码: 遍历"票据号码："标签后面所有行，找10位以上纯数字行（排除8位票据代码）
- 日期: 匹配文本末尾的 `YYYY-MM-DD` 格式
- 项目名称: 匹配 `(\d+\s*(?:发明|实用新型|外观设计)专利[^\n]*)` 模式
- 金额: 找"金额合计（大写）"标签和大写金额之间的数字行，取第一个小数（排除订单号等长数字）

## 2. 浙江省公路车辆通行费票据（电子）

**示例**: 5月7日五常-南湖43.57元.pdf, 4月2日临平-南湖28.5.pdf

**特征**:
- 标题: `浙江省公路车辆通行费票据（电子）`
- 字段名: `票据号码`（不是"发票号码"）
- 日期格式: `YYYY-MM-DD`（如 `2026-05-07`）
- 项目名称无星号标记

**v8 解析逻辑**:
- 票据号码: 匹配 `票据号码[：:]\s*(\d{8,30})` 同行格式
- 日期: 匹配 `开票日期[：:]\s*(\d{4}[-/]\d{1,2}[-/]\d{1,2})`
- 项目名称: 匹配 `(?:^|\n)(\d{6,})\s*\n\s*([\u4e00-\u9fa5]+)` — 独立数字行后的中文名称
  - 必须用 `(?:^|\n)` 前缀避免匹配到"票据代码：33021026\n票据号码"这种标签行
- 金额: 匹配 `（小写）43.57`（策略0）

## 3. 关键坑点

| 坑点 | 说明 |
|------|------|
| 标签后面找数字 | 非税收入票据的"票据号码："标签后面可能是空的，实际数字在几十行之后 |
| 大写金额附近取数字 | 不能取最大数字（会取到标准列900.00），要找大写金额前最近的小数行 |
| 独立数字行匹配 | 通行费的项目编码（50012405）后面是项目名称，但正则要避免匹配"票据代码：33021026\n票据号码" |
| 回测全量 | 每次改 parser 后必须回测全部33张发票，确保不破坏已有格式 |
